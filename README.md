# The Book Blog Club

A full-stack book discovery and discussion platform enabling users to review titles, curate blog boards, and publish literary posts. 

🔗 **Live Deployment:** [thebookblogclub-ashahjg5ccazedc8.canadaeast-01.azurewebsites.net](https://thebookblogclub-ashahjg5ccazedc8.canadaeast-01.azurewebsites.net)

---

## 🛠️ Tech Stack

*   **Frontend:** React, JavaScript, HTML, CSS
*   **Backend:** PHP, Apache (REST API Architecture)
*   **Database:** MySQL
*   **Deployment & Hosting:** Microsoft Azure

---

## 🚀 Current Status & In-Progress Work
*   **Frontend Modernization:** Actively migrating the user interface architecture to **React** to improve component reusability, state management, and dynamic search/pagination flows.
*   **Feature Development:** Refining board and post styling, and expanding pagination handling across local MySQL records and external API fallbacks.

---

## ✨ Core Features
*   **Secure Authentication:** Google OAuth v2 sign-in integration for seamless user onboarding.
*   **Hybrid Search & Discovery:** Multi-source search combining local database queries (titles/authors) with fallback integration to the Open Library API.
*   **Interactive Pagination:** Optimized pagination supporting large result sets across database limits.
*   **Community Engagement:** Custom blog boards, post creation, and comprehensive book reviews with star ratings.
*   **RESTful Architecture:** Clean separation of concerns with a PHP/Apache backend serving JSON endpoints to the client.

---

## 🎯 Development Goals
This project is built to strengthen and demonstrate expertise in:
*   Full-stack web architecture and migration patterns (Vanilla JS to React)
*   Relational database design, complex SQL joins (`GROUP_CONCAT`), and pagination
*   Consuming and structuring REST APIs
*   UI/UX design and responsive application layouts
